# R2.GearCalc — Support

R2.GearCalc is a gear ratio calculator for drift and race cars: gearbox +
Winters Performance quick change rear end + tire size → wheel speed per gear,
RPM drop on shifts, and an RPM vs speed chart.

## FAQ

**Why do calculated final drive ratios differ slightly from the Winters
catalog table?**
The app computes ratios from exact tooth counts (e.g. 4.12 R&P is 33/8 =
4.125). The printed catalog rounds inconsistently, so a difference of ±0.01
is expected — the app's numbers are the physically exact ones.

**Where is my data stored?**
Everything is stored locally on your device. See [Privacy Policy](PRIVACY.md).
