# R2.GearCalc — Privacy Policy

_Last updated: August 25, 2026_

R2.GearCalc works fully offline by default and collects no data unless you
explicitly enable an optional cloud feature. There are no analytics, no
advertising, no tracking, no accounts, and no third-party data sharing.

## Data we process only if you opt in

**Push notifications (off by default).** If you enable Notifications in the
app, we store your anonymous push token (an identifier issued by the
notification service) together with the app language and app version, solely
to send you notifications about app updates, new R2 Motorsport apps and
offers. Turning the toggle off deletes the token from our server. The token
is not linked to your identity and is never used for tracking.

**Cloud backup (off by default).** If you enable Cloud backup, a copy of your
app settings (gear sets, gearboxes, presets, notes you typed) is stored on
our server under a random backup code shown in the app. The backup is not
linked to your identity; whoever knows the code can restore it, so treat the
code like a password. When you turn the backup off, the app offers to delete
the server copy; you can also delete it at any time this way.

Cloud data is stored in Google Firebase (EU region). The app also contacts
Expo Application Services to deliver over-the-air updates of the app's own
code; no user data is transmitted for this.

## Everything else stays on your device

All calculator settings live on your device and are included in your normal
iPhone backups. Deleting the app deletes this data.

If this policy changes, the updated version will be published at this page
before the change takes effect.
